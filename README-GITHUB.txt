LOLAZY PORTFOLIO — 3 PAGE WEBSITE

Files:
- index.html : Home / Lolazy logo + animated background
- work.html  : Work / Portfolio categories (7 tiles)
- about.html : About + Contact
- images/lolazy-logo.png : Logo asset

To publish:
1. Upload all files and the images folder to the root of your GitHub repository.
2. In GitHub, open Settings > Pages.
3. Choose Deploy from a branch, select main and /(root), then Save.
4. Open the Pages URL after deployment finishes.

To replace a category tile with a project later, edit work.html.
Update the tile text and link, or add individual project pages and link each tile to them.
